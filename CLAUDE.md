# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

- `npm ci` — install dependencies from `package-lock.json`.
- `npm run dev` — Next.js development server at `http://localhost:3000`.
- `npm run build` — production build; `npm run start` — serve that build.
- `python scripts/pack-frames.py` — rebuild the scroll video frame packs (needs ffmpeg with libwebp).
- `npm run lint` — ESLint; `npm run lint -- src/components/forma/FormaPage.tsx` — lint one file.
- `npx tsc --noEmit` — TypeScript check.
- `node --experimental-strip-types --test src/components/forma/content.test.mts` — run the current content tests with Node 25. There is no configured project-wide test runner or `test` script.

## Architecture

- Next.js App Router, React 19, TypeScript (`@/*` resolves to `src/*`), Tailwind 4. Routes are under `src/app/[locale]`; the `(auth)` route group contains placeholder account screens. `src/app/[locale]/page.tsx` renders the Forma furniture landing page from `src/components/forma/`. The README is the unmodified create-next-app template and does not describe this application.
- `next-intl` routing is configured in `src/proxy.ts` and `src/i18n/{routing,request}.ts`: Azerbaijani is the default unprefixed locale, English is also accepted. `[locale]/layout.tsx` validates the locale, sets Forma metadata and loads Josefin Sans (the only site font, `--font-josefin`, variable weight + italic, `latin-ext` for Azerbaijani letters), and mounts `QueryProvider`, `NextIntlClientProvider`, and Sonner. The furniture page copy currently follows the Azerbaijani reference for both locales.
- `src/components/forma/FormaPage.tsx` composes the four scroll-story panels, color controls, philosophy/stats/services, pinned workshop, horizontal product collection, and showroom footer. `forma.css` contains the scoped cream/ink/green design and responsive/reduced-motion treatments; `content.ts` contains swatches, product data, and workshop chapters. Product and workshop Unsplash assets are stored locally under `public/forma/` and served at `/forma/...`.
- The sofa canvas is loaded dynamically from `studioScene.ts` only on the client. It loads real glTF models (`public/forma/models/sofa.glb`, `chair.glb`), drives a GSAP scroll timeline over `#story`, explodes the model parts with a blueprint box and live dimension lines, exposes fabric colour updates, and releases WebGL resources on unmount.
- Scroll-scrubbed video lives in `public/forma/seq/*.bin` frame packs built by `python scripts/pack-frames.py` from the clips in `public/forma/videolar/` (144 WebP frames per clip at 24 fps; the script also regenerates `src/components/forma/framePacks.ts` with byte sizes). `frameStore.ts` downloads every pack once while the curtain shows a real byte percentage and slices frames with zero-copy `Blob.slice`; the curtain only lifts after all packs and the fully pre-warmed 3D studio (`onComplete`: chair shaders/textures compiled via `compileAsync`) are ready. `frameSequence.ts` decodes frames off the main thread with `createImageBitmap` (cropped to the canvas cover rect), keeps a direction-aware window of decoded bitmaps around the current frame, closes the rest, and paints the nearest decoded frame so playback never freezes. Packs drive the services window (`craft`), the pinned `#film` section (`room`), the pinned `#seq` workshop (`shop1`-`shop4` played back to back with a dip-to-black at each cut), one collection card (`living`) and the footer band (`lathe`). Keep roughly 10 px of scroll per frame when changing pin lengths.
- `ShowroomWalk.tsx` is its own route, `src/app/[locale]/magaza/page.tsx` (`/magaza`); a fixed "Showroom-a bax" button next to the home navbar links to it with a circle-reveal transition (`openStore` in `FormaPage`). The page does not scroll: wheel/keys/touch move a virtual position (`SPEED` frames per wheel px, smoothed by `LERP` each rAF) over the `store1`-`store5` packs (`public/forma/videolar/magaza/V1-V5.mp4`, full clips chained end frame → start frame), with holds at the hall (category bar from `STORE_CATEGORIES`) and at each sofa (`STORE_SOFAS`: info panel, colour swatches, order drawer that opens a `mailto:`). Colour variants are stills in `public/forma/magaza/` crossfaded over the stop frame. `store*` packs are excluded from the home curtain; the store page loads them itself with `loadPacks()` behind its own loader. Scrolling into the sofa section snaps to the first sofa; after that each new wheel gesture (separated by `STOP_IDLE` ms) glides automatically to the next/previous sofa. Setting `DEBUG = true` in `ShowroomWalk.tsx` shows a corner overlay with `FrameSequence.stats()` (target/shown frame, hits/misses, decoded bitmaps and memory). `next.config.ts` sends a one-day `Cache-Control` for `/forma/*`.
- Old real-estate components remain in `src/components/landing/` because they include pre-existing local edits, but the home route no longer imports or renders them. Do not reconnect the residence-specific header, crane, contact form, frame sequence, or building scene to the furniture page.
- `src/providers` implements TanStack Query client/SSR hydration. `src/lib/api/client.ts` is an Axios wrapper with an optional `NEXT_PUBLIC_API_BASE_URL`, cookie bearer token, and locale header; the furniture page currently uses a `mailto:` contact CTA instead of an API endpoint.
